# Sources and coverage

## Primary source and extraction scope

Janice (Ginny) Redish, *Letting Go of the Words: Writing Web Content That Works*, second edition, Morgan Kaufmann/Elsevier, 2012. ISBN **978-0-12-385930-3**.

The synthesis covers all 15 chapters and five interludes. The coverage map below shows where their lessons appear in the skill. No copy of the book is needed to use the package.

The skill contains original paraphrases and actionable interpretations, not the ebook, extracted text, screenshot collection, or a replacement edition. Repetition across chapters is consolidated by task. Historical examples support decision rules; old company facts, statistics, links, laws, and product instructions are not presented as current facts. Chapter and interlude numbers are used rather than unverifiable ebook page numbers.

Attribution: the book credits Leslie O’Flahavan with “bite, snack, meal” and Caroline Jarrett with “launch and land.” Its discussion of information scent builds on Pirolli, Card, and colleagues; its account of satisficing references Herbert Simon. The operational guardrails about factual preservation, authorized scope, and honest reporting of agent verification are adaptations for this skill.

## Interpret historical advice carefully

| Historical advice or context | How this skill handles it |
| --- | --- |
| Specific headline, sentence, list, line-length, scroll, video-size, or duration targets | Treat as diagnostic heuristics. Preserve purpose and test the actual context rather than imposing universal thresholds. |
| Search-engine rankings and particular algorithm claims | Retain useful audience vocabulary and clear structure. Do not promise rankings; verify current technical SEO claims when needed. |
| Old social platform names, limits, and interface steps | Preserve channel-appropriate brevity and continuity. Verify current platform behavior for an actual implementation task. |
| Broad rules against dark backgrounds, serif fonts, centered text, or horizontally scrolling tables | Keep readability and task completion as the criteria. These are context-sensitive choices, not universal bans or current standards. |
| Custom font-size controls on every site | Preserve usable text enlargement and reflow; do not require a specific widget without need. |
| A prescribed position for in-page links | Preserve predictable distinction between in-page and off-page navigation; respect current, tested product patterns. |
| Descriptions for all mood images | Use contextual alt-text decisions, including empty alternatives for decoration. |
| A single alt description for complex charts or interactive maps | Supply appropriate extended data/text and an operable equivalent for interaction. |
| JavaScript show/hide described as inherently accessible | Require proper control semantics, state, keyboard behavior, and appropriate focus/reading order. |
| Every chart should begin at zero | Preserve honest visual encoding. Bars normally need zero; other chart types need a scale chosen and disclosed for the analytical task. |
| Gender and language conventions from 2012 | Use current inclusive language, known pronouns, and the reader’s language conventions. |
| Unmoderated studies characterized as lacking think-aloud | Evaluate the actual tool and research design; do not assume a permanent tool limitation. |
| Sample counts, conversion uplifts, or age-based behaviors in case studies | Do not generalize them into guarantees or claims about a new audience. |
| Model privacy policy and old legal references | Use only as historical writing examples, never as a compliant template or evidence of a service’s practices. |

These adaptations preserve the book’s underlying goals while avoiding unsupported claims that its specific implementation details remain current.

## Official skill-authoring guidance consulted

Checked 20 October 2026:

- [OpenAI: Build skills](https://learn.chatgpt.com/docs/build-skills) — focused scope, explicit inputs and outputs, instructions over unnecessary scripts, trigger checks, and optional Codex metadata.
- [Anthropic: Skill authoring best practices](https://platform.claude.com/docs/en/agents-and-tools/agent-skills/best-practices) — concise entry point, precise discovery description, progressive disclosure, direct reference links, and realistic evaluations.
- [Agent Skills specification](https://agentskills.io/specification) — portable directory layout and required name/description frontmatter.
- [Claude Code: Extend Claude with skills](https://code.claude.com/docs/en/skills) — personal skill installation and invocation; local skills are distinct from account-level Claude/Cowork skills.
- [Claude: Use skills](https://support.claude.com/en/articles/12512180-use-skills-in-claude) — ZIP-folder upload for Claude’s account-level skill interface.

This package uses the common SKILL.md format and relative reference links. The optional agents/openai.yaml file supplies Codex UI metadata. It does not depend on either assistant’s proprietary tools, a local book path, a CLI, or a network connection for normal writing tasks.
